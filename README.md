# 🌐 Meu Primeiro Site

Meu primeiro projeto desenvolvido utilizando **HTML5 e CSS3**.
Este projeto faz parte da minha jornada de aprendizado em desenvolvimento web.

## 📚 Objetivo

O objetivo deste projeto é colocar em prática os primeiros conceitos de desenvolvimento web, incluindo:

* Estrutura básica de uma página HTML
* Elementos e semântica HTML
* Seletores CSS
* Cores, fontes e espaçamentos
* Organização de elementos
* Layout e estilização
